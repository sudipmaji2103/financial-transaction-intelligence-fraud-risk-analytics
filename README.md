# Financial Transaction Intelligence & Fraud Risk Analytics

##  Project Overview

This project analyzes financial transaction data to identify fraud patterns, quantify risk exposure, and support data driven fraud investigation and decision-making.

The project combines transaction-level analysis with customer, merchant, device, card, geographic, payment-method, and risk indicators to build a comprehensive view of financial fraud risk.

##  project Objective

The primary objectives of this project are to:

- Monitor transaction and fraud performance
- Identify high risk customers, merchants, devices, and payment methods
- Analyze geographic fraud concentration
- Detect unusual transaction behavior
- Evaluate fraud risk exposure
- Define risk detection thresholds
- Support fraud investigation and prioritization
- Convert analytical findings into actionable business insights
